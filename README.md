# go-iot-seamstress

Archived Go + MQTT solution for piecework payroll control and end-to-end work-in-progress (WIP) tracking in a garment factory, from cut pieces to finished goods.Zero-button hardware: Minimal action required from shop-floor workers.Single SQLite DB: Lightweight, embedded, and easy to deploy.User-friendly Web UI: Total control and beautiful stats for the production manager.
